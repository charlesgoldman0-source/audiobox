Playlist to search list Ready

Turn a Spotify, Apple Music or SoundCloud playlist into a copy-paste search list for Soulseek. Paste a playlist link to start, or a single song's link to add it to the list. No account needed. Audiobox reads track names only and never downloads anything from any of them.

Sign in to read your private playlists

Signing in covers Spotify. Apple Music offers no sign-in without a paid Apple Developer membership, and SoundCloud no longer issues API keys, so share a playlist on either of those publicly and paste its link.

Spotify allows only five signed-in users per app, so Audiobox cannot ship a shared login. Create your own free app on the Spotify developer dashboard, add the redirect URL below to it, then paste its Client ID here. This takes a few minutes once. Creating an app needs Spotify Premium.
